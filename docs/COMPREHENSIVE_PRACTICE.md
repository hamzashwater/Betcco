# Comprehensive Practice Assignment

Comprehensive Practice is the formative final activity for a delivered canonical BTEC Unit. It reuses `CourseAssignment`, submission versions, private scanned files, effective deadline extensions, and `TrainingOutcome`. A `CourseAssignment` with `Purpose = ComprehensivePractice` is linked to one `CourseModule` with a `UnitDefinition`; it has no lesson or individual Learning Aim link. The filtered unique index allows only one Comprehensive Practice per delivered module while retaining historical coursework and Learning Aim Practice rows.

The learner can start, upload, and submit only with an active course enrollment, valid course and Unit release, a published activity within its effective deadline, and **every** canonical Learning Aim complete. The existing `LearningAimPracticeProgressService` defines Aim completion as completed published content plus finalized teacher review with a training outcome. An empty canonical Aim set or mismatched delivery mappings fail closed. The Unit can have any positive number of canonical Aims. A finalized Comprehensive Practice review after all Aims are complete is displayed as **Unit Training Complete**. This is not official Unit achievement or certification.

Teachers can create the Unit Practice, upload supporting materials, link existing canonical criteria from multiple Aims within the same Unit, and finalize a review with one formative outcome, strengths, gaps, and improvement guidance. The criterion links are contextual only. The catalogue may have Units without populated canonical criteria; those Units show no criterion choices. No Pearson criterion identities are inferred or fabricated.

The service's guarded database update makes teacher finalization terminal: a concurrent second request returns conflict and cannot overwrite feedback or add a second successful review audit. The database uniqueness constraint also protects simultaneous creation. Historical submissions remain reviewable by the course teacher after learner access expires, provided an enrollment record proves course provenance. Expiry blocks new learner activity. Learner and teacher file downloads continue through the private storage authorization endpoint; storage keys are not returned by the API.

Comprehensive Practice does not create `EvaluationRequest`, alter `EvaluationGrade`, write formal `CriterionResult`, or enter the coursework gradebook. Existing coursework calculations filter `Purpose = Coursework`. The additive migration creates only the filtered unique index. Its rollback removes that index, which removes the new duplicate prevention; it does not delete assignment data. The source-level enum uses the numeric value 2 for this purpose, so existing values 0 and 1 retain their meaning.
