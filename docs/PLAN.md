# BETCCO delivery plan

1. Foundation, documentation, local infrastructure, and quality tooling.
2. Identity, authorization, database schema, migrations, and idempotent seed.
3. Public BETCCO site, CMS branding, catalog, discovery, and SEO.
4. Teacher authoring and administrator course approval.
5. Cart, verified payments, enrollment, invoices, and immutable accounting.
6. Course player, private resources, progress, quizzes, and assignments.
7. BTEC evaluation request, secure submission, assignment, teacher review, and student result.
8. Operations: notifications, support, live sessions, blog, CMS, and reporting.
9. AI Tutor, analytics, final security review, and end-to-end verification.

Each phase must pass its formatter, static checks, build, and relevant tests before the next phase.
